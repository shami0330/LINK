# LINK — پیام‌رسان

نسخهٔ مستقل و قابل نصب به‌شکل PWA. فایل `index.html` برنامهٔ اصلی است؛ آیکون‌ها، manifest و service worker برای نصب و بازشدن پوستهٔ برنامه در حالت آفلاین کنار آن قرار دارند.

رابط مخصوص حالت عمودی موبایل است؛ در گوشی، اگر صفحه افقی شود، پیام چرخاندن دستگاه به حالت عمودی نمایش داده می‌شود. manifest نصب PWA نیز جهت عمودی را درخواست می‌کند.

## انتشار در GitHub Pages

1. تمام محتویات این پوشه را در ریشهٔ یک مخزن GitHub قرار بده.
2. در مخزن، از **Settings → Pages**، انتشار از شاخهٔ موردنظر و پوشهٔ `/ (root)` را فعال کن.
3. لینک HTTPS ساخته‌شده را باز کن. پس از بارگذاری، از منوی مرورگر گزینهٔ **Install app / Add to Home Screen** را انتخاب کن.

PWA و service worker روی `file://` کار نمی‌کنند؛ برنامه را از HTTPS (مانند GitHub Pages) یا `localhost` باز کن.

## نکتهٔ اتصال

پوسته، HTML و آیکون‌ها کش می‌شوند تا برنامه پس از بازدید اولیه نیز به‌صورت PWA باز شود. ورود، گفتگوها، ارسال پیام، همگام‌سازی و دریافت Appwrite به اتصال اینترنت نیاز دارند. service worker درخواست‌های حساب و پیام‌ها را ذخیره نمی‌کند.

پروژهٔ Appwrite در HTML پیکربندی شده است؛ برای فعال‌کردن ورود و realtime، دامنهٔ GitHub Pages را در فهرست پلتفرم‌های Web پروژهٔ Appwrite ثبت کن. شناسه‌های عمومی پروژه جایگزین API key نیستند؛ هیچ API key مدیریتی را در مخزن قرار نده.

ویدیوپیام‌های تازه هنگام ارسال یک تصویر پیش‌نمایش کوچک از فریم اول می‌سازند و کنار ویدیو در Storage ذخیره می‌کنند. با لمس پیام، خود ویدیو دریافت می‌شود و حلقهٔ دریافت دور آن پیشرفت را نشان می‌دهد. ویرایش پیام‌های متنی/دارای فایل برای پیام‌های ارسالی فعال است؛ اگر مجوز ردیف‌های قدیمی Appwrite اجازهٔ update ندهد، خطای ویرایش نمایش داده می‌شود.

متن برنامه قابل انتخاب یا کشیدن نیست. مدت ویدیوپیام بیرون از حباب گرد، در سمت مقابل زمان ارسال نمایش داده می‌شود.

## مجوزها و کش

مجوز دوربین و میکروفون فقط هنگام شروع ضبط درخواست می‌شود. انتخاب پوشه و کش محلی به قابلیت‌های مرورگر وابسته است؛ پاک‌کردن داده‌های سایت یا لغو مجوزها از تنظیمات مرورگر بر رفتار آن‌ها اثر می‌گذارد.

## فایل‌ها

- `index.html` — برنامهٔ LINK
- `manifest.webmanifest` — مشخصات نصب PWA
- `sw.js` — کش پوسته و fallback آفلاین برای HTML
- `icons/` — آیکون پیکسلی برنامه و نسخه‌های PNG نصب
